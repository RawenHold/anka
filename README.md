# ANKA — дорога и дом

Личный сайт Анны и Сергея: знакомство с авторами, каталог выпусков, карта мест из видео, музыка и ссылки на их площадки. Проект собирается в статические файлы. Для обновления данных нужен работающий процесс или внешний планировщик.

## Запуск

Нужен Node.js и npm.

В Windows можно дважды нажать `Открыть сайт.cmd` в папке проекта. Команда запустит локальный просмотр и откроет его в браузере. Если порт 4174 занят другим сайтом, сначала освободите его.

```powershell
npm install
npm run dev
```

Vite напечатает локальный адрес. Production-сборка создаётся командой:

```powershell
npm run build
```

Готовые файлы лежат в `dist/`; их можно разместить на обычном статическом хостинге. Для локального просмотра сборки используйте `npm run preview`.

## Обновление канала

При `npm run dev`, `npm run preview` и `npm run serve` процесс раз в час проверяет новые выпуски и публичный счётчик подписчиков. Браузер повторно запрашивает сохранённый снимок каждые пять минут. Для рабочего сервера сначала выполните `npm run build`, затем `npm run serve`; процесс должен оставаться включённым. Разовый запуск: `npm run sync:channel`. Последние корректные данные сохраняются в `public/data/channel-live.json`; ошибка сети не стирает каталог.

Без ключа используется публичная лента YouTube (обычно около 15 последних публикаций) и публичная страница канала. Если сайт долго не работал, лента может не содержать все пропущенные выпуски. Для обхода полного плейлиста можно задать серверную переменную `YOUTUBE_API_KEY` с ключом YouTube Data API. Число подписчиков YouTube публикует округлённым; разбор публичной страницы может перестать работать, если YouTube изменит её устройство.

Пробег обновляется только при достаточно явном упоминании их Volvo и показания одометра в доступных описаниях или русских субтитрах новых видео. Текст субтитров доступен не всегда; распознавание аудио не подключено. В таком случае остаётся последнее подтверждённое значение с датой, а не расчётный текущий пробег. Ссылки на музыку в описаниях новых выпусков добавляются в музыкальный раздел и окно видео; если название или обложка не указаны, выводится общая подпись и кадр выпуска. Музыка, не упомянутая в описаниях, автоматически не распознаётся.

На статическом хостинге сам по себе браузер не обновляет данные с YouTube: нужен серверный планировщик, сборка и повторная публикация. Подготовлен `.github/workflows/sync-channel.yml`, но он не запущен и не настроен для этого проекта. Если развёртывание идёт через отдельный GitHub Actions workflow, коммит от `GITHUB_TOKEN` обычно не запускает его автоматически — настройте публикацию явно. Сайт пока не опубликован.

## Оформление

Главная реализует выбранный пользователем яркий макет: фотография авторов, навигация с торшером, показатели и четыре перехода к основным разделам. Дневная и ночная темы переключаются торшером в шапке; выбор сохраняется в браузере. Временный переключатель прежних концепций удалён из интерфейса.

## Что есть на сайте

- Поиск по названиям, описаниям, местам и главам выпусков; категории, сортировка и список сохранённого.
- YouTube-плеер с главами. Он загружается после открытия выпуска; оригинал доступен по ссылке из окна просмотра.
- Если YouTube запрещает встраивание или сообщает об ошибке плеера, окно предлагает открыть выпуск на YouTube; выбранная глава сохраняется в ссылке. Проверка доступности встраивания для сохранённого архива запускается командой `node scripts/audit-embeds.mjs` и обновляет `src/data/embed-availability.json`. Разрешения могут измениться, поэтому снимок нужно периодически обновлять и пересобирать сайт.
- В окне выпуска есть кнопка «Музыка»: она показывает найденные в описании песни, ссылки на площадки и отметки времени. Если сведений нет, это указано отдельно.
- Музыкальный список с поиском по названию, исполнителю и выпуску, фильтром площадок и кнопками Suno, YouTube и перехода к моменту в видео.
- Раскрытая карточка каждого автора оформлена в выбранном варианте «Разворот»; ссылка на Instagram закреплена внизу окна.
- Одно изображение Volvo; рядом — модель, год покупки и пробег на дату выпуска.
- Карта Leaflet на тайлах OpenStreetMap. Нужен интернет и видимая атрибуция внизу карты. Точки приблизительные и связаны с упоминаниями в видео; это не GPS-трек.
- Дневной и ночной режим: торшер со шнуром расположен в шапке и меняет оформление всего сайта.
- Адаптивные версии для телефона и компьютера, управление с клавиатуры и поддержка системного режима уменьшения анимации.

Переключатель фильтра «Сохранённые» адаптирован из [Uiverse — Switch by Shoh2008](https://uiverse.io/Shoh2008/average-duck-41), лицензия MIT. Текст лицензии и уведомление об авторстве — в `THIRD_PARTY_NOTICES.md`.

## Данные и изображения

Исходные редакционные материалы находятся в `js/data.js`. В `src/data/channel-catalog.json` сохранены 232 записи публичного плейлиста загрузок канала, полученные 17 ноября 2026 года. Приватные и удалённые видео в него не входят. `src/data/archive.js` объединяет эти данные с ручной разметкой; некоторые рубрики и упоминания мест определены по тексту и требуют редакционной проверки. Для обновления каталога предназначен `scripts/import-channel-catalog.mjs`; команды экспорта описаны в начале скрипта и требуют установленного отдельно `yt-dlp`.

`src/data/music-sources.json` собран по 230 доступным описаниям выпусков: в нём есть прямые ссылки, названные композиции со ссылкой на поиск и неразрешённые упоминания. `src/data/music-by-video.js` связывает эти сведения с карточками выпусков. У 21 видео есть хотя бы одна ссылка на композицию или поиск, у 62 — упоминание музыки без названия; группы пересекаются. Для 155 выпусков в подготовленных данных таких сведений нет. Это не проверка звучания каждого ролика. Публичные страницы Suno дают изображения треков; для YouTube используется превью музыкального видео.

Портреты Ани и Сергея и обложка канала предоставлены пользователем и лежат в `public/images/creators/`. В разделе Volvo используется прежняя сгенерированная иллюстрация `front.webp`; кадры из выпуска сохранены отдельно. Источники — в `public/images/truck/SOURCES.md` и `public/images/research/SOURCES.md`.

Поиск охватывает имеющиеся названия, описания, главы, теги и отдельные фрагменты субтитров, но не полную речь в каждом видео. Для выпусков без авторских глав доступны переходы к моментам по автоматическим субтитрам; в таких текстах возможны ошибки. В девяти выпусках без субтитров отмечены проверенные отдельные кадры. Это не полная разметка сцен. Исходные данные фрагментов — `src/data/caption-moments.json`, генератор — `scripts/extract-caption-moments.mjs`. SEO-настройка, семантические группы и условия публикации описаны в `SEO.md`.

Декоративный контур США создаётся командой `node scripts/build-map-silhouette.mjs` из существующего в проекте `data/us-states.geojson`. Точки на нём приблизительные; линий маршрута нет. Exo 2 установлен локально через `@fontsource-variable/exo-2`, лицензия шрифта — `node_modules/@fontsource-variable/exo-2/LICENSE` (SIL Open Font License 1.1).
