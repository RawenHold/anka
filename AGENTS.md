# ANKA — дорога и дом
Обновлено: 2026-11-19; проверено по `src/`, `js/data.js`, `public/images/`, `README.md` и локальной сборке.

- Цель: тёплый личный сайт Анны и Сергея от их лица. Главные сценарии: познакомиться, найти выпуск, посмотреть его и исследовать места из видео.
- Границы: сохранять проверяемые факты, названия выпусков и исходные материалы. Не придумывать цитаты, GPS-маршруты и полноту архива относительно канала.
- Стек: React 19 и Vite; Leaflet/OpenStreetMap для карты; Boxicons через локальные данные иконок. Статическая сборка; для автообновления нужен постоянно работающий Node-процесс или настроенный планировщик и перепубликация.
- Источники данных: `src/data/channel-catalog.json` — 232 публичных загрузки YouTube на 17.11.2026; `src/data/archive.js` объединяет их с редакционной разметкой из `js/data.js`; `src/data/music-sources.json` — музыка из описаний. Кадры и их источники — `public/images/research/`.
- Ключевые файлы: `src/App.jsx` — сценарии и первый экран; `src/components/PersonDialog.jsx` — выбранный вариант карточек «Разворот», `VideoMusicDialog.jsx` и `src/data/music-by-video.js` — музыка конкретного выпуска, `TruckSection.jsx` — галерея и характеристики. `src/concept-neon.css` и `src/music-redesign.css` — выбранное оформление; `DESIGN.md` — описание дизайн-системы. Старые `src/concepts.css` и `src/concept-album.css` содержат базовые стили и прежние варианты.
- Запуск и проверка: `npm install`, `npm run dev`, `npm run build`; `npm run preview` показывает собранную версию.
- Решения: точки карты приблизительные, подписаны и не соединены в GPS-трек. OpenStreetMap требует интернет и видимую атрибуцию. Pull Cord переключает тему всего сайта; Uiverse-переключатель фильтрует сохранённые выпуски.
- Состояние: реализована выбранная пользователем концепция по `.impeccable/mocks/approved-home.png`. Новые портреты и обложка пользователя — в `public/images/creators/`. Для карточек авторов выбран «Разворот» с закреплённой ссылкой на Instagram. Локально проверены desktop и мобильные экраны, музыка выпуска с переходом к таймкоду, карточки авторов и галерея трака. Плеер и внешние ссылки зависят от сервисов; публикации не было.
- Ограничения: 232 записи снимка получили рубрики по заголовкам и описаниям, часть требует редакционной проверки; поиск индексирует доступные метаданные, главы и выборочные фрагменты, но не полную речь. 199 выпусков имеют главы; ещё 24 — переходы по автоматическим субтитрам, девять — по отдельным кадрам. Это не полная проверенная разметка всех сцен. `scripts/channel-sync.mjs` обновляет публичную ленту и счётчик; RSS ограничена последними публикациями, полный обход требует серверного ключа YouTube Data API. В новых видео ссылки на музыку из описания автоматически добавляются через `src/data/live-music.js`; названия и обложки не определяются, аудио не распознаётся. Пробег извлекается только из доступных и однозначных текстовых свидетельств, без распознавания аудио. Галерея использует четыре кадра реального Volvo из выпуска; источники — `public/images/truck/SOURCES.md`. На карте 30 приблизительных точек, не все связи означают посещение. Карта зависит от тайлов; сайт не публиковался. SEO-подготовка — `SEO.md`; SITE_URL нужен для canonical и sitemap.
- Детали: `README.md` — запуск, данные и функции; `sources/personality-report.md` — только неподтверждённое редакционное исследование, не источник биографических фактов. Элементы из папки пользователя `Btech/Сайт компании/MD` изучены; блик кнопки и сетка адаптированы без демонстрационных данных.
